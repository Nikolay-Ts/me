A minimalist, macOS-native **LaTeX & Markdown editor** built for large academic
projects — the kind where one thesis is spread across dozens of files. It keeps a
dependency graph of the project so subfiles recompile correctly, and pairs a live
editor with a rendered preview.

Written in Kotlin Multiplatform with Compose Desktop. It has autocomplete and an
intellisense-style completion engine, math parsing and rendering, a spell checker
backed by per-project and per-user dictionaries, syntax highlighting, split-pane
tiling, find & replace, undo history, PDF export and macOS share-sheet
integration.
